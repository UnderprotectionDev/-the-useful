# The Useful Parts — MVP specs ve ticket'lar

31 workflow fazının spesifikasyonları ve 55 uygulanabilir yerel ticket. Faz numaraları kaynak workflow ile eşleşir. Ticket numaraları tüm MVP için tektir ve bağımlılık sırasındadır.

- Her spec problem, çözüm, kullanıcı hikâyeleri, uygulama kararları, test kararları, kapsam sınırları ve PRD izlenebilirliğini içerir.
- Her ticket bağımsız bir doğrulanabilir iş dilimidir. `Blocked by` alanı yalnız doğrudan önkoşulları gösterir. Önkoşulları tamamlanan işler başlatılabilir.
- PRD §14.0 teknik prototipi, faz 17 ile ilişkili erken doğrulama ticket'ı olarak ilk sıradadır. Özel web erişimi bağımsız başlayabilir.
- PRD §15.2 kabul senaryoları birden fazla dilimi kapsayabilir. Tüm MVP davranışları tamamlandığında iki hedef istemci ve web üzerinden ilgili senaryolar tekrar doğrulanır.
