# 01: Codex ve Claude Code ile MCP teknik prototipini doğrulama

**Spec:** [Ajan Bağlantılarını Yönetme](../spec.md)

**What to build:** İki hedef istemciyle küçük MCP prototipinde keşif, tam içerik okuma, gerçek görsel ve dosya erişimi ile dosyalı Item oluşturma uygulanabilirliğini doğrula.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] Küçük bir özel test kütüphanesinde iki hedef istemciyle Collection arama ve seçilen Item'ın tam okuması doğrulanır.
- [ ] Her iki istemci gerçek görseli inceler, kod ve özgün dosyaları alır.
- [ ] İki istemcide yeni Item oluşturma, görsel/dosya aktarımı ve oluşturulan içeriğin tekrar erişilebilmesi doğrulanır.
- [ ] İstemci bazında sonuçlar kaydedilir. Gerçek medya veya aktarım desteği başarısızsa erişim tasarımı/hedef istemci ve PRD yeniden değerlendirilir.
