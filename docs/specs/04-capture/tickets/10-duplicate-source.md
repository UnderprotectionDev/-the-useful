# 10: Yinelenen kaynak URL uyarısı

**Spec:** [İçeriği Kütüphaneye Kaydetme](../spec.md)

**What to build:** Yinelenen normalize URL için kullanıcı mevcut Item'ı tanıyabilsin ve isterse açıkça ayrı kayıt oluşturabilsin.

**Blocked by:** [08 — Tek içerikle hızlı kayıt](../../04-capture/tickets/08-quick-capture.md)

**Status:** ready-for-agent

## Acceptance criteria

- [ ] Normalize URL Active/Archived Item'da bulunursa mevcut kimlik ve ayırt edici bilgi gösterilir.
- [ ] Kullanıcı vazgeçebilir veya açıkça ayrı kayıt oluşturabilir.
- [ ] Trash'teki URL olağan tekrar kontrolüne girmez; uyarıdan ayrıntıya geçiş detail ticket'ında tamamlanır.
